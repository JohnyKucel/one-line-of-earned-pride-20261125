## The entry

> After forty years of night shifts, my father hung his own name above the workshop door and stood there a while, just looking at it.

## How it works

Run `python3 main.py`. It writes the single line above to `/output/entry.txt`
as UTF-8 text with no trailing newline, validating that it is 1–240
characters long first. Python standard library only, no dependencies.
